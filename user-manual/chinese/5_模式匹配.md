
# 模式匹配

模式匹配主要用于 `is` 表达式和 `match` 语句场景。

模式匹配的目的是为了检查一个表达式的结构是否和预期的一样，也允许把内部的值取出来绑定到新的变量上。

示例如下：

```
// 变量 x 是一个 tuple，有 3 个元素，且把第二个元素绑定到 middle 变量上，再判断 middle > 5 是否成立
if (x is (_, middle, _)) && middle > 5 {

}

// 变量 y 的类型是指向 trait 的指针，我们可以用这种方式，判断 y 实际指向的具体类型是什么。如果判断成功，这个指针就被绑定到 p 上。
if y is p: *S {
    // p can be used inside block
}

// 变量 z 是 Option<S> 类型，下面分别对 Some 和 None 两种场景做处理
match z {
    Some(s) => {

    }
    _ => {}
}
```

与表达式类似，模式也是可以嵌套的。

## WildcardPattern

占位符模式。

`_` 下划线可以占据一个位置。

`...` 省略号可以占据多个位置。

## LiteralPattern

允许整数、浮点数、Bool、Char等类型的字面量直接作为模式使用。

`Str` 字面量模式暂未实现。

## TypePattern

类型模式主要用于判断一个表达式是不是某个具体的子类型。类型模式以 `type` 关键字开头。

示例：
```
// 假设 TR 是一个 trait 名字，S 是一个 struct 名字。
// 下面这句话用于判断一个指向 trait 的指针，是不是可以成功向下转型为指向 S 的指针。
fn test(p: &TR) {
    let b = p is type &S;  // 使用 type 关键字开头，是为了避免与后面的 modifier+identifier 模式发生语法冲突
}
```

## StructPattern

结构体模式用于匹配结构体类型的值，并可以解构其成员变量。

示例：
```rust
struct Point { x: Int, y: Int }

fn test(p: Point) {
    // 匹配结构体，将成员变量绑定到新变量
    if p is { .x = a, .y = b }: Point {
        println(f"x = $(a), y = $(b)");
    }
    
    // 使用省略号忽略其他成员
    if p is { .x = 10, ... }: Point {
        println("x is 10");
    }
    
    // 嵌套模式匹配
    match p {
        { .x = 0, .y = 0 } => println("origin");
        { .x = 0, .y = y } => println(f"on y-axis at $(y)");
        { .x = x, .y = 0 } => println(f"on x-axis at $(x)");
        { .x = x, .y = y } => println(f"point ($(x), $(y))");
    }
}
```

## TuplePattern

元组模式用于匹配元组类型的值，并可以解构其元素。

示例：
```rust
fn test(t: (Int, String, Bool)) {
    // 匹配元组，将元素绑定到新变量
    if t is (num, str, flag) {
        println(f"num = $(num), str = $(str), flag = $(flag)");
    }
    
    // 使用下划线忽略某些元素
    if t is (1, _, true) {
        println("first element is 1 and third is true");
    }
    
    // 嵌套元组模式
    let nested = ((1, 2), (3, 4));
    if nested is ((a, b), (c, d)) {
        println(f"($(a), $(b)), ($(c), $(d))");
    }
}
```

## EnumVariantPattern

枚举变体模式用于匹配枚举类型的特定变体，并可以解构其关联值。

示例：
```rust
enum Message {
    Quit,
    Move(Int, Int),
    Write(String),
}

fn test(msg: Message) {
    match msg {
        Message::Quit => println("quit");
        Message::Move(x, y) => println(f"move to ($(x), $(y))");
        Message::Write(text) => println(f"write: $(text)");
    }
}
```

## ModifierPattern

修饰符模式用于在模式匹配中控制变量的绑定方式。

- `mut`：将绑定的变量标记为可变
- `&`：匹配引用
- `&mut`：匹配可变引用
- `ref`：通过引用绑定，而不是移动
- `ref mut`：通过可变引用绑定

示例：
```rust
fn test(s: String) {
    // mut 修饰符：使绑定的变量可变
    let mut x = s;
    x.push_str(" modified");
    
    // ref 修饰符：通过引用绑定，避免移动

    // ref mut 修饰符：通过可变引用绑定

}
```

## IdentifierPattern

标识符模式用于将匹配的值绑定到一个变量名上。

示例：
```rust
fn test(x: Int) {
    // 简单标识符绑定
    if x is y {
        println(f"y = $(y)");
    }
    
    // 在 match 中使用
    match x {
        0 => println("zero");
        n => println(f"other: $(n)");
    }
    
    // 结合其他模式使用
    let tuple = (1, 2, 3);
    if tuple is (first, ...) {
        println(f"first = $(first)");
    }
}
```
