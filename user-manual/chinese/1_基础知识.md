# 基础知识

## hello world

一段基本的 zinc 程序源代码如下所示：

```rust
fn main() {
    println("hello world");
}
```

源代码文件以 `.zn` 扩展名结尾，文件内容必须用 utf8 编码。编译命令为：

```
zinc main.zn
```

执行完毕，我们就可以在当前文件夹下看到一个新生成的可执行程序，执行这个程序，可以打印出 `hello world` 这个字符串。

## 注释

zinc 支持两种注释：行注释和块注释。

1. 行注释

    行注释以 `//` 开头，一直到本行结尾结束。

2. 块注释

    块注释以 `/*` 开头，一直到第一个 `*/` 结束。

## 函数

普通的 zinc 函数定义，用 `fn` 关键字开头，后跟着函数名和一对圆括号，圆括号内部是这个函数的参数列表。在圆括号后面可以写函数的返回类型。再后面是大括号包围的函数体。

示例如下：

```rust
fn my_func(arg1: Int32, arg2: String) -> Bool {
    return true;
}
```

如果一个 zinc 项目，需要生成可执行程序，那么它就需要在根模块中定义唯一的一个 `main` 函数，作为程序入口。

## 变量和类型

标识符：以 `_` 或者字母开头，后面允许 `_` 或者数字或者字母。

单独的 `_` 是特殊的标识符，表示忽略。

> **TODO**：目前还不支持 unicode 标识符和 raw identifier，待实现。

### 局部变量

局部变量允许不显式标记类型，允许类型推导。

变量名没有用 mut 修饰的情况下，默认是不可变的。

```rust
fn main() {
    let x = 5_i;
    x = 6; // 错误，x 不可变
}
```

为了可读性，同一个 block 中的局部变量，**不** 允许重名。不同 block 中的局部变量当然是可以重名的。

### 静态变量

静态变量的定义，用 `static` 关键字修饰。

静态变量的类型，需要满足 `Send` 约束 (注意哪些类型满足 `Send` 跟 Rust 不同)，参考“并行并发”章节。如果要用 un-Send 类型作为 static 变量，则必须用 unsafe 修饰。

静态变量定义时必须初始化，且初始化表达式只能是“常量表达式”。

静态变量可以带 mut 修饰。但是 mut 静态变量必须用 unsafe 修饰。对它的读写，都必须在 unsafe 上下文中。

```rust
unsafe static mut G: Int32 = 1; // 带 mut 修饰的 static 变量, 或者类型不满足 Send 的 static 变量, 必须用 unsafe 修饰

fn main() {
    println(G.to_string()); // 错误，G 只能在 unsafe 上下文中使用
}
```

> **计划中的功能**：后续可以支持 static 变量的类型推导。

### 常量

常量的定义，用 `const` 关键字修饰。

与静态变量类似，常量的类型，必须满足 `Send` 约束。常量定义时必须初始化，且初始化表达式只能是“常量表达式”。

常量不能带 mut 修饰。

```
const PI: F32 = 3.14;
```
> **计划中的功能**：后续可以支持 const 常量的类型推导。
